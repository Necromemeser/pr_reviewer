# PR Reviewer Microservice

PR Reviewer — микросервис для управления pull request'ами, командами и пользователями, реализованный на Go с использованием PostgreSQL и Docker.

## Запуск

Для запуска проекта достаточно выполнить команду:

```
docker-compose up
```

Сервис поднимет контейнеры с приложением и базой данных PostgreSQL. После запуска все маршруты API будут доступны на соответствующих эндпоинтах.

## Основные возможности

- Создание и получение команд (Team).

- Создание, слияние и переназначение ревьюеров для pull request'ов (PullRequest).

- Управление статусом пользователей (User) и получение списка их PR.

### Безопасная переназначаемость PR

При переназначении ревьюера соблюдаются следующие правила:

- Нельзя переназначать ревьюера для уже объединенного (MERGED) PR.

- Ревьюер может быть заменен только на другого активного пользователя своей команды, который в этот момент не является вторым ревьюером данного PR.

- Если нет доступного кандидата для замены, операция отклоняется с кодом ошибки NO_CANDIDATE.

### Расширение API и коды ошибок

Для упрощения обработки ошибок и унификации API были добавлены два новых кода ошибок:

- BAD_REQUEST — некорректные входные данные.

- SERVER_ERROR — внутренняя ошибка сервера.

Все остальные доменные ошибки (PR_EXISTS, TEAM_EXISTS, NOT_ASSIGNED, PR_MERGED, NO_CANDIDATE, NOT_FOUND) также возвращаются с соответствующими HTTP-кодами.

### Ограничения и допущения

Для простоты реализации и тестирования сделано допущение, что конкурентных запросов на одну и ту же сущность (PR, команду или пользователя) пока не будет.

Таким образом, возможны гонки данных, если одновременно пытаться изменить один и тот же PR или пользователя из нескольких запросов.


### Тестирование

Проект покрыт юнит-тестами с использованием gomock. Для запуска тестов:

```
go test ./...
```


Тесты проверяют корректность работы всех маршрутов API, включая успешные сценарии и обработку ошибок.
